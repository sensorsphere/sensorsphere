# NET-UI-03 — User access and command lifecycle

## Permissions
- Netatmo Heating navigation, overview and journal available to authenticated User and Admin.
- SIM-02 thermostat control available to User and Admin (OAuth write_thermostat required).
- Netatmo Connections, OAuth authorization, discovery, manual collection, and configuration remain Admin-only.
- Server-side role guard implemented for heating overview, journal and control. Simulator target lock (SIM-02 + fixed endpoint) remains enforced on server.

## Durable command journal
- Migration 093 creates netatmo_command_journal, indexed by connection and time, with request identity, mode, setpoint, duration, status, simulator HTTP result, readback and collected confirmation.
- States: pending, accepted, verified, mismatch, failed, unknown. Unknown explicitly means command outcome uncertain, not necessarily rejected.
- The UI displays the 25 most recent commands for the selected connection and refreshes the journal every 15 seconds.
- Command API records the attempt before sending, and logs clear upstream/OAuth errors without storing tokens.
- Post-collection reconciliation uses collected room mode and, for manual commands, temperature within 0.05°C; only collected telemetry can yield verified. Earlier accepted commands superseded by a later accepted command become unknown.
- No automatic command execution as part of deployment; SIM-01 and physical devices remain read-only.
