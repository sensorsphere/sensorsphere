## Implementation
- Four responsive `Card withBorder` tiles styled like the Dashboard summary: indoor temperature (simulator cyan #46c8f0), setpoint (amber #f2ae5b), outdoor (violet #9d8cff), boiler status (green #69d9a7).
- Simulator 0.5.22 extends its OAuth-protected `/api/homestatus` with optional `outdoor_temperature` and `boiler_fault` fields. Existing `boiler_status` continues to carry the simulated boiler activity.
- SensorSphere Netatmo telemetry parses these optional fields and ingests two new metrics `outdoor_temperature` and `boiler_fault` on the existing thermostat asset; no schema migration required.
- Boiler card shows simulator `FAULT`, `HEATING` or `IDLE` using simulated fault + heating status. External/physical Netatmo connections remain `Unknown` unless independently verified boiler feedback becomes available. Missing outdoor data also remains clearly unavailable for real connections; no fabricated values.
- Simulator-only field additions are optional and backwards-compatible with real Netatmo API responses.
