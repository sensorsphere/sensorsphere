# NET-UI-01 / NET-UI-02 — Heating supervision and control (DEV)

## Scope
- New admin-only navigation page **Netatmo Heating** (distinct from technical **Netatmo Connections**).
- Reads existing Netatmo device registry and latest persisted observations; no extra Netatmo API polling from UI.
- Shows connection OAuth permissions, collection timestamps and errors; thermostat measured temperature, setpoint, mode, heating demand, reachability, battery and measurement freshness.
- Shows relay separately, with parent/child topology and last registry contact. No invented relay or boiler live status: heating demand is not proof of boiler operation.
- Controls for SIM-02 only: manual 7–30 °C by 0.5 °C, 30m/1h/2h/4h, schedule/away/hg. Modal confirmation before each command, immediate API readback distinguished from collected telemetry.
- Explicit read-only for SIM-01 and real equipment, enforced by both frontend and existing backend SIM-02 target guard. Backend additionally checks persisted write_thermostat scope.
- Disable controls when data is stale or device unreachable. 30-second refresh does not overwrite command drafts.
- Links to Assets, Device Registry, History, and Connection Settings.
- Existing control form removed from technical connections page.
- No schema migration, no TEST1 changes, no push.
